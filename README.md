# pokelecture

## Lire avec les Pokémon

Jeu de lecture et de compréhension pour le CE1, à utiliser à la maison.
Ouvrir `index.html` dans un navigateur (tablette, ordinateur ou téléphone). Rien à installer.

- 9 courts textes sur les Pokémon, en 3 niveaux (de 22 à 75 mots), chacun illustré par le décor de son histoire.
- Lecture avec réglage de la taille du texte (A− / A+).
- Chasse aux mots : 3 mots à toucher dans le texte pendant la lecture. Les trouver tous fait gagner un cristal.
- QCM de compréhension : 3 questions par texte, le texte est caché (bouton « Revoir le texte » disponible). Après chaque réponse, la phrase du texte qui la justifie est affichée. 1 étoile par bonne réponse.
- 2 bonnes réponses ou plus font gagner le compagnon du texte : 9 créatures originales à collectionner, chacune avec un accessoire tiré de son histoire.
- Bouton « Menu » pendant les questions, espace parent avec le meilleur score par texte et la remise à zéro.
- La progression est enregistrée dans le navigateur (localStorage), sur l'appareil utilisé.

`lire-avec-les-pokemon.html` est la même page sans l'en-tête HTML (version publiée en Artifact).
